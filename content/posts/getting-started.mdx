## Welcome to Reverie

This is your first post in Reverie — a local content management tool with an MDX editor and AI-assisted writing.

### Features

- **Rich MDX editing** with Tiptap
- AI-powered writing assistance
- Local file storage
- Live preview

### Code Example

```typescript
const greeting = "Hello, Reverie!"
console.log(greeting)
```

### What's Next?

Start by exploring the editor. Try formatting text, adding code blocks, or inserting images.
